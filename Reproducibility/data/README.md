Datasets used in this study include NASA, PROMISE, AEEEM, and BugHunter.



The directory structure is organized as follows:



classification/datasets/

├── NASA/        # Processed NASA software defect datasets

├── PROMISE/     # Processed PROMISE repository datasets (e.g., JM1, KC1)

├── AEEEM/       # Processed AEEEM datasets

└── BugHunter/   # Processed BugHunter dataset



Due to license restrictions, the original raw datasets are not redistributed.

Only the processed feature files required to reproduce the experiments are included.

Instructions for obtaining the original datasets are provided in the corresponding publications.
